# Roadmap — Этапы разработки

---

## Фаза 1: Фундамент (Неделя 1-2)

**Цель:** видеть токены и логировать сигналы, без реальных сделок.

### Задачи
- [ ] Настроить проект (pyproject.toml, .env, структура папок)
- [ ] Подключить pump.fun WebSocket — слушать новые токены
- [ ] Подключить DexScreener API — получать метрики токенов
- [ ] Реализовать базовые Rule Filters (ликвидность, холдеры, возраст)
- [ ] Настроить БД (SQLite) — сохранять все виденные токены
- [ ] Структурированное логирование (structlog)
- [ ] Rugcheck API интеграция

**Результат:** скрипт запускается, видит новые токены, логирует те что прошли фильтры.

```bash
[2025-01-15 14:23:01] NEW TOKEN: $BONK2 | liq=134 SOL | holders=445 | age=3min
[2025-01-15 14:23:01] FILTER PASS: rule_score=7.2 → sending to AI
[2025-01-15 14:23:03] FILTER FAIL: $SCAM | reason=top10_holders=73%
```

## Фаза 2: Twitter + AI (Неделя 2-3)

**Цель:** добавить социальные сигналы и AI анализ.

### Задачи
- [ ] Подключить Twitter API — поиск упоминаний по тикеру
- [ ] Создать KOL whitelist (10-20 аккаунтов для начала)
- [ ] Реализовать AI Analyzer (Claude API вызовы)
- [ ] Настроить пороги скора (начать с 7.0, настраивать)
- [ ] Paper trading лог — записывать "что бы купил" с ценами входа
- [ ] Бэктестинг на исторических данных pump.fun

**Результат:** система предлагает сделки и логирует их результаты (виртуально).

```bash
[2025-01-15 14:25:03] AI ANALYSIS: $BONK2 | ai_score=8.4 | reasoning="Strong KOL signal..."
[2025-01-15 14:25:03] PAPER TRADE: BUY 0.2 SOL of $BONK2 at $0.0000234
[2025-01-15 16:45:00] PAPER RESULT: $BONK2 +340% | would have made +0.68 SOL
```

## Фаза 3: Исполнение сделок (Неделя 3-4)

**Цель:** реальные сделки с маленьким депозитом.

### Задачи
- [ ] Реализовать wallet.py (загрузка keypair)
- [ ] Jupiter API интеграция — получение котировок
- [ ] Trade Executor — buy и sell функции
- [ ] Position Manager — отслеживание открытых позиций
- [ ] Price monitoring loop (каждые 10 сек)
- [ ] Автоматические продажи по триггерам (x2, x4, x10, стоп-лосс)
- [ ] Тест на devnet с фейковыми токенами

**Результат:** бот реально покупает и продаёт токены на Solана.

**Стартовый депозит: 0.5 SOL** (для тестирования)

## Метрики успеха

| Метрика | Неудовлетворительно | Хорошо | Отлично |
|---------|---------------------|--------|---------|
| Win rate | < 30% | 35-50% | > 50% |
| Avg winner | < x1.5 | x2-x3 | > x4 |
| Max drawdown | > 50% | 20-40% | < 20% |
| ROI / месяц | < 0% | 20-50% | > 100% |

**Главное правило:** если за 2 недели paper trading система убыточна — не переходить к реальным деньгам, анализировать и фиксить фильтры.
